# dim

dim / 3D Application based on SVG for graphic designers
Based on concepts of svg, bezier curves, B-spline curves, perspective projection, orthographic projection, oblique projection.

You can easily import (copy & paste) 2D path images from Adobe Illustrator CC (or other vector graphic softwares) to a 3D space and view, transform, extrude, revolve, sweep, map to a spline or a surface.
You can export (copy & paste) the result back to Adobe Illustrator.

Inspired from Adobe dimensions(3.0J),
